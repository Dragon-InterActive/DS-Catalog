InstallierenInstall

Am einfachsten mit einem Befehl – er lädt den Launcher, prüft die Prüfsumme und lässt ihn sich selbst installieren (Startmenü, Rechteabfrage): Easiest with one command – it downloads the launcher, checks its checksum and lets it install itself (start menu, asks for rights):

Linux, macOS

Im Terminal:In a terminal:

curl -fsSL https://catalog.dragon-software.net/install.sh | sh

Skript ansehenView the script

Windows

In PowerShell:In PowerShell:

irm https://catalog.dragon-software.net/install.ps1 | iex

Unter macOS installiert das Skript über Homebrew. Unter Windows fragt SmartScreen so nicht nach – ein über den Browser geladenes Archiv muss man erst „zulassen“. On macOS the script installs with Homebrew. On Windows SmartScreen does not ask this way – an archive downloaded with the browser has to be „unblocked“ first.

Erster StartFirst start

  1. Windows, Linux (heruntergeladen): das Archiv entpacken und bin/ds-launcher (Windows bin\ds-launcher.exe) starten. Unter „Programme“ den DS-Launcher selbst installieren – danach steht er im Startmenü und hält sich und die anderen Programme aktuell.
  2. macOS (Apple Silicon): mit Homebrew installieren (Befehl oben), dann ds-launcher starten; er legt sich und die installierten Programme unter „Programme“ an.
  3. Unter „Voraussetzungen“ prüft der Launcher Rust, rust-analyzer, clippy, rustfmt, den Debugger und (Linux) GTK 4 und hilft beim Nachinstallieren.
  1. Windows, Linux (downloaded): unpack the archive and start bin/ds-launcher (Windows bin\ds-launcher.exe). Under „Programme“ (programs) install the DS-Launcher itself – then it is in the start menu and keeps itself and the other programs up to date.
  2. macOS (Apple Silicon): install it with Homebrew (command above), then start ds-launcher; it adds itself and the installed programs to Applications.
  3. Under „Voraussetzungen“ (prerequisites) the launcher checks Rust, rust-analyzer, clippy, rustfmt, the debugger and (Linux) GTK 4 and helps installing what is missing.
